# Warning Label for Humans: One Line, Big Laugh

A single-line comedy entry for the make.fun bounty: the safety warning label that should come printed on every human being. Funny first, plausible second — a real product-warning voice applied to the most universal human defect of all: what we agree to after midnight.

> WARNING: Do not operate after midnight; this unit may agree to anything, remember nothing, and blame the firmware in the morning.

The joke lands because everyone recognises it in themselves: late-night confidence, next-morning amnesia, and blaming anything but the operator. Phrased as a genuine label — `WARNING`, `Do not operate`, `this unit` — so it reads like something that could plausibly be stamped on the box.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed). Stdlib only — no third-party packages, no network.
